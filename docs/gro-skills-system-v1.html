Gro Skills

把个人 AI 编程工作流表达为阶段契约：明确入口、交付物、完成证据、权限和停止条件，同时把通用思考过程交还给模型。

13 skillsnon-linear workflowcontract over tutorial

设计原则

统一的是契约语义，不是强迫所有 skill 填同一套章节。只有会改变行为的内容才进入 SKILL.md。

模型能力不重复教学

删除通用分析、问话和风险枚举教程；保留用户自己的流程和高代价边界。

产出必须可消费

每个阶段说明下游拿到什么，以及哪些可观察事实证明阶段完成。

按脆弱度给精度

多条路径都可行时给目标和约束；不可逆、易漂移或有失败样本时才固定步骤。

非线性系统地图

从当前风险所在阶段进入。轻量任务可以跳过上游产物；跨阶段能力、异常分支和显式动作不是必经节点。

13 个阶段契约

卡片只展示独立价值；具体行为以对应 SKILL.md 为真源。

定义与设计

定目标

set-goal

多轮收敛，只有用户确认后才交付目标卡。

写需求

write-brief

让人能判断做不做、做成什么样。

做设计

make-design

明确边界、流转、接口、取舍和验证策略。

写规格

write-spec

让下一位 AI 不重读原资料也能执行。

执行与交付

拆计划

make-plan

默认落库，成为跨 session 的执行和防偏移基线。

开始做

build-it

按计划实现、逐步验证并记录偏移。

验证它

prove-it

用新鲜证据给出四态结论。

做评审

review-it

findings 优先，检查规格覆盖、证据和剩余风险。

证据与异常

找证据

find-proof

本地优先，必要时用外部证据交叉验证和矫正。

挑毛病

poke-holes

显式挑战具体主张，不接管普通评估。

修问题

fix-bug

不复现不猜修，不确认根因不扩大改动。

显式交付动作

提交代码

commit-it

明确授权后分组 commit；只有额外明确授权才 push。

记经验

save-lesson

仅从当前 session 取证，按授权写入正确作用域。

正文 house style

最小内核保持一致，工作流、分支、验证、交互、资源和示例只在会改变行为时增加。

模块回答的问题去留标准
目标与边界本阶段造成什么改变，不承担什么职责？能说明独立价值，且不复述 description。
产出与完成判据下游拿到什么，什么事实证明完成？产物可消费，证据可观察。
关键约束什么边界会改变结果、权限或安全？有真实失败依据或高代价风险。
停止与交接何时停止，什么事实触发下一阶段？用事实路由，不自动演完整流程。

持续回归，而不是持续加字

模型或 skill 机制大版本变化后，固定客户端、模型和用例，重跑有 skill / 无 skill 对照。把存量指令分为“仍必要、已冗余、可能有害”；删掉后行为没有变差的指令永久删除。
